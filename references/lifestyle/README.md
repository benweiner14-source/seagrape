# Lifestyle photography references

Real reference images Ben pulled that nail the aesthetic described in `PROJECT_BRIEF.md`'s
"Lifestyle Photography Direction" section — Ralph Lauren editorial, J.Crew sailboat shots,
Lafarve, unbothered European courtyard energy. Use these as **style references** when generating
lookbook lifestyle shots in Higgsfield/Seedream (attach alongside a Printful mockup of the actual
tee), the same way LonnieAI attaches `reference-material/2k-screenshots/` frames as a style
target.

## What's here

- **`ralph-lauren-boat-nap.jpg`** — guy asleep on a teak sailboat bow, newspaper over his face,
  arms behind head, sparkling water. This **is** the reference for lookbook Shot 1 (the
  MacArthur-tee boat nap) already described in `PROJECT_BRIEF.md` — match this framing/light
  exactly, shot from slightly above.
- **`jcrew-sailboat-catalog.jpg`** — actual J.Crew catalog tearsheet, guy reclined on a teak deck,
  cream tee + navy shorts + boat shoes. The canonical "J.Crew sailboat shot" reference named in
  the brief — relaxed, natural light, teak deck, no performance for camera.
- **`european-courtyard-cafe.jpg`** — guy at a café table in a stone courtyard, sunglasses, white
  tee, jeans, sandals, mid-conversation, not looking at camera. The "unbothered, not performing"
  energy the brief calls out — good reference for any non-boat/non-golf lookbook shot.
- **`vintage-film-laundromat.jpg`** — retro film photography, heavy grain, warm light leaks,
  candid off-camera gaze. Reference for the **film stock/grain/color-grade** treatment, not the
  wardrobe or setting — apply this texture quality to on-brand scenes, don't copy the laundromat.
- **`lafarve-dock-graphic-tee.webp`**, **`lafarve-backyard-graphic-tee.jpg`**,
  **`lafarve-beach-candid.jpg`** — real Lafarve lookbook/campaign shots (Lafarve is one of the
  brief's named comparable brands). Reference for how a **graphic tee** should sit in a candid
  lifestyle shot: relaxed fit, logo legible but not the focus, real settings (dock, backyard grill,
  beach) rather than a studio. Note Lafarve's photos lean more streetwear/saturated than Seagrape's
  target (warmer, more faded, more Ralph Lauren/J.Crew) — use these for **composition and
  candid-energy** cues, not color grading.

## How to use these in a generation prompt

Same pattern as the brief's Higgsfield prompt formula — describe the shot in text, then attach
one of these as a style reference so the model has a concrete target instead of guessing at
"1980s editorial" from words alone. If the tool only accepts one reference image, prioritize
`ralph-lauren-boat-nap.jpg` or `jcrew-sailboat-catalog.jpg` for boat/golf scenes, and
`european-courtyard-cafe.jpg` for anything land-based and off-water.
